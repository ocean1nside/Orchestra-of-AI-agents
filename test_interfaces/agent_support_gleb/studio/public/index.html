Добавить документ в базу знаний

Файлы проходят обязательную ИИ-подготовку в Markdown, затем индексация. Статус «В поиске» — документ в поиске бота.

Как подготовить файл (кратко)

Форматы: Markdown (.md), текст UTF-8 (.txt), Word (.docx). PDF не поддерживается — сохраните в .md или .docx.

Нарезка: по абзацам и заголовкам (~1000 симв., перекрытие ~150), не по середине слов.

  • Одна тема на файл; разделы ##, шаги списком.
  • Грязный Word/docx → кнопка «Подготовить через ИИ», затем проверка на вкладке «Текст».
  • Шаблон: docs/handover/knowledge-content-template.md

Гайд: docs/handover/knowledge-documents-guide.md

Выберите или перетащите файл .md · .txt (UTF-8) · .docx

После выбора файла запустится ИИ-подготовка (обязательно). Проверьте текст на вкладке «Текст», затем загрузите.

Чанки документа

Как готовить документы для базы знаний

1. Процесс

  1. «+ Добавить документ» → файл или текст.
  2. Понятное название + галочка «Сразу проиндексировать».
  3. В списке статус В поиске — можно проверять бота.

2. Форматы файлов

ФорматКомментарий
.mdЛучший вариант: заголовки, списки, UTF-8
.txtUTF-8, абзацы пустой строкой
.docxАбзацы и ячейки таблиц
PDFНе поддерживается → конвертируйте в .md / .docx

3. Нарезка на чанки

Сначала границы абзацев и ## заголовков, затем предложения и слова; лимит ~1000 символов, перекрытие ~150. До 8 чанков в ответ бота.

3a. Подготовка через ИИ

Кнопка в модалке загрузки: переписывает .md/.txt/.docx в структурированный Markdown без выдуманных фактов. Требуется OPENAI_API_KEY. После — вкладка «Текст», правки, загрузка.

4. Как писать, чтобы хорошо искалось

  • Один смысл — один абзац (300–1200 символов), между темами — пустая строка.
  • Конкретика: «Настройки → Пользователи → Импорт», коды ошибок, обязательные поля.
  • Заголовки # / ## для структуры (в .md).
  • Не одна простыня на 50 страниц без разрывов.
  • Не сканы без текста; не cp1251 — только UTF-8 для .txt/.md.

5. Пример фрагмента (.md)

# Импорт пользователей

Импорт: Настройки → Пользователи → Импорт.

## Формат CSV

UTF-8. Колонки: email, role.

## Шаги

1. Откройте раздел пользователей.
2. Загрузите CSV и дождитесь «Завершено».

6. Если не находится в ответах

  • Статус «В поиске»? Иначе — Reindex документа.
  • Вопрос ближе к словам из документа.
  • В проде для семантики: OpenAI-эмбеддинги + полный reindex.
