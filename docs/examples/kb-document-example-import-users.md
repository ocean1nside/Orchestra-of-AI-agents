# Импорт пользователей через CSV

Кратко: как массово добавить пользователей в систему из файла CSV. Документ для операторов и администраторов.

## Когда использовать

- Нужно загрузить список сотрудников или клиентов из Excel или Google Таблиц.
- Количество строк не больше 10 000 за один импорт.

## Предусловия

- Роль «Администратор» или право «Управление пользователями».
- Файл сохранён в формате CSV, кодировка UTF-8.

## Пошаговая инструкция

1. Откройте Настройки → Пользователи.
2. Нажмите кнопку «Импорт».
3. Выберите файл CSV на компьютере.
4. Дождитесь статуса «Завершено» в журнале импорта внизу экрана.

## Форматы и ограничения

- Формат: CSV, разделитель запятая или точка с запятой.
- Кодировка: только UTF-8 (в Excel: «Сохранить как» → CSV UTF-8).
- Обязательные колонки: email, role.
- Необязательные колонки: name, department.

## Частые ошибки

### Код E100 — ошибка кодировки

Причина: файл сохранён в Windows-1251 или Excel «CSV (разделитель — запятая)» без UTF-8.

Что сделать: пересохранить файл в UTF-8 и повторить импорт.

### Сообщение «Пользователь уже существует»

Причина: в файле есть email, который уже есть в системе.

Что сделать: удалить дубликаты из CSV или обновить пользователей вручную в карточке.

## Связанные разделы

- Сброс пароля пользователю — отдельный документ «Сброс пароля».
- Экспорт списка пользователей — Настройки → Пользователи → Экспорт.
